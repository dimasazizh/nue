# NUE Item Markers Compatibility

An optional Meitou 0.23.1 add-on for NUE Unified or NUE Inventory Avatar and the modern Item Markers mod. It redraws the grade frames, stars, and status badges on NUE's equipment tiles, prosthetic slots, and expanded weapon racks. Item Markers supplies the artwork, colors, and settings. NUE supplies the final slot bounds and icon position.

The mod folder is named `ItemMarkersCompat`. Its runtime files are `ItemMarkersCompat.mod`, `meitou.json`, and `Nue.ItemMarkersCompat.dll` from this project. Enable the add-on after NUE and Item Markers in the launcher.
